## 블록 요소

### 제목 (Headings)

제목은 `#` 기호를 사용하여 작성합니다. `#`의 개수에 따라 제목 레벨이 결정됩니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `# 제목 1` | <h1>제목 1</h1> | `<h1>제목 1</h1>` |
| `## 제목 2` | <h2>제목 2</h2> | `<h2>제목 2</h2>` |
| `### 제목 3` | <h3>제목 3</h3> | `<h3>제목 3</h3>` |
| `#### 제목 4` | <h4>제목 4</h4> | `<h4>제목 4</h4>` |

**예시:**
```markdown
# 메인 제목
## 소제목
### 하위 제목
#### 세부 제목
```

---

### 인용구 (Blockquote)

`>` 기호로 인용구를 만들 수 있습니다.

| 문법 | HTML |
|------|------|
| `> 인용 텍스트` | `<blockquote>인용 텍스트</blockquote>` |

**예시:**
```markdown
> 이것은 인용구입니다.
> 여러 줄로 작성할 수 있습니다.
```

**결과:**
> 이것은 인용구입니다.
> 여러 줄로 작성할 수 있습니다.

---

### 순서 있는 리스트 (Ordered List)

숫자와 점(`.`)을 사용하여 순서 있는 리스트를 만듭니다.

| 문법 | HTML |
|------|------|
| `1. 항목 1`<br>`2. 항목 2` | `<ol><li>항목 1</li><li>항목 2</li></ol>` |

**예시:**
```markdown
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목
```

**결과:**
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목

---

### 순서 없는 리스트 (Unordered List)

`-`, `*`, `+` 중 하나를 사용하여 순서 없는 리스트를 만듭니다.

| 문법 | HTML |
|------|------|
| `- 항목 1`<br>`- 항목 2` | `<ul><li>항목 1</li><li>항목 2</li></ul>` |

**예시:**
```markdown
- 첫 번째 항목
- 두 번째 항목
- 세 번째 항목
```

**결과:**
- 첫 번째 항목
- 두 번째 항목
- 세 번째 항목

---

### 체크리스트 (Checklist)

할 일 목록을 만들 때 사용합니다.

| 문법 | 설명 |
|------|------|
| `- [ ] 할 일` | 체크되지 않은 항목 |
| `- [x] 완료` | 체크된 항목 |

**예시:**
```markdown
- [ ] 프로젝트 기획
- [x] 디자인 완료
- [ ] 개발 진행 중
- [x] 테스트 완료
```

**결과:**
- [ ] 프로젝트 기획
- [x] 디자인 완료
- [ ] 개발 진행 중
- [x] 테스트 완료

### 수평선 (Horizontal Rule)

`---`, `***`, `___` 중 하나를 사용하여 수평선을 만듭니다.

| 문법 | HTML |
|------|------|
| `---` | `<hr>` |

**예시:**
```markdown
위 내용

---

아래 내용
```

**결과:**

위 내용

---

아래 내용

### 코드 블록 (Code Block)

백틱(`` ` ``) 3개로 코드 블록을 감쌉니다.

**예시:**
````markdown
```
function hello() {
  console.log("Hello World!");
}
```
````

**결과:**
```
function hello() {
  console.log("Hello World!");
}
```

### 테이블 (Table)

`|`, `---`, `:` 을 조합하여 표를 만듭니다.

**예시**
```markdown
| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Cell 1   | Cell 2   | Cell 3   |
| Cell 4   | Cell 5   | Cell 6   |
```

**결과**
| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Cell 1   | Cell 2   | Cell 3   |
| Cell 4   | Cell 5   | Cell 6   |

---

#### 정렬 옵션

**문법**
```markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:---------|:----------:|----------:|
| Left     | Center     | Right     |
| 왼쪽     | 중앙       | 오른쪽    |
```

**정렬 규칙:**
- `:---` → 왼쪽 정렬 (기본값)
- `:---:` → 가운데 정렬
- `---:` → 오른쪽 정렬

**결과**
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:---------|:----------:|----------:|
| Left     | Center     | Right     |
| 왼쪽     | 중앙       | 오른쪽    |

|------|------|:----:|

#### 작성 팁

✅ 좋은 예시

1. **열 너비 일관성 유지**
```markdown
| Name  | Age | City     |
|-------|-----|----------|
| Alice | 25  | Seoul    |
| Bob   | 30  | Busan    |
```

2. **헤더는 명확하게**
```markdown
| 이름 | 나이 | 도시 |  ✅ 명확함
| A    | B    | C    |  ❌ 불명확함
```

3. **정렬 일관성**
```markdown
| 항목 | 수량 | 가격 |
|------|-----:|-----:|  ✅ 숫자는 오른쪽 정렬
```

---

#### ⚠️ 주의사항

1. **최소 구조 필수**
   - 헤더 행 (Header)
   - 구분선 (Separator)
   - 데이터 행 (최소 1개)

2. **파이프 필수**
```markdown
| Header |     ✅ 올바름
Header       ❌ 파이프 없음
```

3. **구분선 형식**
```markdown
|--------|     ✅ 올바름
|========|     ❌ 잘못된 기호
```

4. **빈 셀 허용**
```markdown
| Name | Age | City |
|------|-----|------|
| Alice| 25  |      |  ✅ 빈 셀 허용
```

#### 테이블 스타일링

현재 테이블은 다음과 같이 스타일링됩니다:

- **헤더**: 회색 배경, 굵은 글씨
- **셀**: 테두리 있음, 패딩 적용
- **호버**: 행에 마우스 올리면 배경색 변경
- **정렬**: 왼쪽/가운데/오른쪽 정렬 지원
- **반응형**: 넓은 테이블은 가로 스크롤

---

  <table class="min-w-full border-collapse border border-gray-300">

      <tr>

      <tr class="hover:bg-gray-50">

## 인라인 요소

### 굵게 + 기울임 (Bold + Italic)

`***` 또는 `___`로 텍스트를 감싸면 굵게와 기울임이 동시에 적용됩니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `***텍스트***` | ***텍스트*** | `<strong><em>텍스트</em></strong>` |

**예시:**
```markdown
이것은 ***매우 중요한*** 내용입니다.
```

---

### 굵게 (Bold)

`**` 또는 `__`로 텍스트를 감싸면 굵게 표시됩니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `**텍스트**` | **텍스트** | `<strong>텍스트</strong>` |

**예시:**
```markdown
이것은 **굵은 텍스트**입니다.
```

---

### 기울임 (Italic)

`*` 또는 `_`로 텍스트를 감싸면 기울임이 적용됩니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `*텍스트*` | *텍스트* | `<em>텍스트</em>` |

**예시:**
```markdown
이것은 *기울어진 텍스트*입니다.
```

---

### 밑줄 (Underline)

`__`로 텍스트를 감싸면 밑줄이 그어집니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `__텍스트__` | <u>텍스트</u> | `<u>텍스트</u>` |

**예시:**
```markdown
이것은 __밑줄 텍스트__입니다.
```

---

### 취소선 (Strikethrough)

`~~`로 텍스트를 감싸면 취소선이 그어집니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `~~텍스트~~` | ~~텍스트~~ | `<del>텍스트</del>` |

**예시:**
```markdown
이것은 ~~취소된 내용~~입니다.
```

> 에디터에서 텍스트를 선택한 후 `~` 키를 누르면 자동으로 `~~선택텍스트~~`로 감싸집니다.

---

### 인라인 코드 (Inline Code)

백틱(`` ` ``) 1개로 텍스트를 감싸면 인라인 코드가 됩니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `` `코드` `` | `코드` | `<code>코드</code>` |

**예시:**
```markdown
`console.log()` 함수를 사용하세요.
```

---

### 링크 (Link)

`[텍스트](URL)` 형식으로 링크를 만듭니다.

| 문법 | 결과 | HTML |
|------|------|------|
| `[GitHub](https://github.com)` | [GitHub](https://github.com) | `<a href="https://github.com">GitHub</a>` |

**예시:**
```markdown
[Google](https://google.com)에서 검색하세요.
```

---

### 이미지 (Image)

`![대체텍스트](이미지URL)` 형식으로 이미지를 삽입합니다.

| 문법 | HTML |
|------|------|
| `![로고](https://example.com/logo.png)` | `<img src="https://example.com/logo.png" alt="로고">` |

**예시:**
```markdown
![팀 로고](https://example.com/team-logo.png)
```

## 팁과 주의사항

### ✅ 좋은 예시

1. **제목과 본문 사이에 빈 줄 추가**
```markdown
# 제목

본문 내용
```

2. **리스트 항목 일관성 유지**
```markdown
- 항목 1
- 항목 2
- 항목 3
```

3. **코드 블록에 언어 명시 (향후 지원 예정)**
````markdown
```javascript
const hello = "world";
```
````

---

### ⚠️ 주의사항

1. **제목 기호(`#`) 뒤에는 반드시 공백 필요**
```markdown
# 올바른 제목
#잘못된 제목
```

2. **인라인 코드와 코드 블록 구분**
```markdown
`인라인 코드`는 한 줄, 코드 블록은 여러 줄
```

3. **링크 URL에는 프로토콜 포함**
```markdown
[올바른 링크](https://example.com)
[잘못된 링크](example.com)
```
